# AI 对话与策略 DSL V1 实施计划

规格：`docs/ai-assistant-strategy-dsl-v1.md`

架构：`docs/adr/0001-native-ai-assistant-and-strategy-dsl.md`

1. **T-AI-01 合同与测试基线**：定义 DSL 类型、校验错误和 API 类型；先写失败测试。
2. **T-AI-02 DSL 执行回测**：实现指标白名单解释器，并让历史回测执行规范化 DSL。
3. **T-AI-03 持久化模型**：新增对话、消息、每日用量和策略版本表以及 D1 迁移。
4. **T-AI-04 对话 API**：实现所有权隔离、服务端历史、限流、敏感信息拦截和 SSE。
5. **T-AI-05 策略生成 API**：实现受限输入、服务端上下文、LLM JSON 提案、确定性校验和规则模式降级。
6. **T-AI-06 前端集成**：替换静态 Agent 对话，接入持久化会话与流式消息；策略工作室接入真实生成结果。
7. **T-AI-07 版本与审计**：保存不可变策略版本快照，补充生成/回测审计。
8. **T-AI-08 验证**：运行单元测试、类型检查、Lint、构建、渲染测试、安全扫描和提交身份检查。

每个任务以可独立验证的原子提交完成；本分支暂不推送、不创建 PR。
