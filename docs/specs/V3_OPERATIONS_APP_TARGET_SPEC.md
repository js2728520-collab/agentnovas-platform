# Operations V3 目标应用规格

状态：`TARGET`
日期：2026-08-23

## 1. 职责与导航

Operations 负责客户、账户、交易、风控、报表、权限注册链接、运营账号、业务审批和审计。模型密钥、系统部署和技术健康属于 Maintenance。

目标路由包括：总览、客户、账户、交易、风控、数据看板、注册链接、运营账号、审批、RBAC 和授权审计。

明确取消组织架构树、上下级关系图和组织关系管理页面。

## 2. 权限注册链接

- 按五级角色生成链接。
- 生成者只能创建低于自身层级的链接。
- 链接长期可重复使用，手动作废；重生成撤销旧链接。
- 显示角色、数据范围、状态、创建人、创建时间、最近使用和使用次数，不显示完整 token。
- 注册成功立即赋予 published assignment，无人工审批。
- 生成、复制、失败、成功、作废和重生成全部审计。
- 链接泄露响应支持立即撤销、会话排查和受影响账号停用。

## 3. 客户管理

- 服务端分页、搜索、筛选、详情和导出。
- 字段包括注册/登录、VIP、Credits、充值消费、IP、设备、社交方式和归属链路。
- 字段级权限和 scope 同时生效。
- 经理及以上可以在范围内冻结/解冻，填写原因并撤销相关会话/交易能力。
- 历史备注、归属、状态和操作不可覆盖。

## 4. 账户、订单和持仓

- 查看交易所/券商账户类型、环境、连接、权限、余额、持仓和 live readiness。
- 不返回 API Key、Secret、Passphrase 或可复用 credential reference。
- 查询订单、成交、持仓、盈亏、策略、次数、价格、金额和净盈亏。
- Paper、Demo、Live 分开筛选和统计。

## 5. 风控操作

默认只读。撤单、平仓、暂停策略、冻结交易只对授权风控/高级管理员开放；必须 recent MFA、原因、确认、幂等和审计。

修改风险参数、解除全局熔断和资金出站决定需要更高权限与 maker/checker。审批通过不等于外部动作已完成，必须等待执行回执。

## 6. 数据看板

支持用户/组织、标的/策略、订单状态、时间、交易所、净盈亏和财务指标。组织只作为筛选与权限维度，不提供组织树编辑。

指标定义、时区、币种、费用、数据延迟和 book 明确。CSV/Excel 使用同一 scope/PII 谓词并记录生成、下载和过期。

## 7. 运营账号

账号支持查看、停用、恢复和归档，不物理删除审计主体。停用立即撤销所有 Operations Session 和授权。

## 8. 会员、退款、策略与作者业务

- 查看会员订单、USDT 支付、退款申请和优惠结果。
- 策略审核工作流显示回测、模拟盘、风险指标、披露和版本差异。
- 策略订阅费、收益分成和作者/平台分账使用版本化合同和不可变结算事实。
- 所有资金和策略高风险决定禁止自审。

## 9. 验收

- 五级角色链接不会越级；撤销旧链接后不能注册。
- 注册事务没有半完成身份或无 assignment 账号。
- 列表、详情、计数、导出和操作目标 scope 一致。
- Operations 页面没有组织架构入口。
- Secret 和跨客户数据在响应、日志和导出中为零。
- 高风险动作准确区分“审批完成”“执行已接受”“执行成功”。
