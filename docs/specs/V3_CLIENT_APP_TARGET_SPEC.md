# Client V3 目标应用规格

状态：`TARGET`
日期：2026-08-23

## 1. 信息架构

公开区：着陆页、登录、注册、找回、邮箱验证、协议与风险披露。
客户区：总览、行情、AI 助手、交易大厅、策略广场、我的策略、跟单、交易中心、会员、Credits、消息、账户与安全。

公开 `/` 与认证客户总览分离。错误 audience 返回 404；401 回 Client 登录，403 显示无权页而不循环跳转。

## 2. 注册与安全

- 邮箱和国际手机号必填，首期只验证邮箱。
- 客户邀请可重复使用并可重生成。
- 最多 5 台设备并发；显示设备、时间和大致位置。
- 新设备/异地通知，支持单会话和全量撤销。
- 密码、MFA、recovery、recent MFA 和敏感动作确认沿用中央身份合同；当前 MFA 不强制，正式生产按 ADR-0023 开启。

实施状态（2026-08-23）：邮箱/国际手机号必填、24 小时邮箱验证与重发、最多 5 台设备、
新设备/网段变化双通道提醒、单会话及全量撤销已实现并通过并发测试。城市级位置和第 6 台
交互仍按 ADR-0022 待需求方确认；G1 真实邮件送达与生产 MFA 开启态证据尚未完成。

## 3. 行情

- 市场入口覆盖加密、A/HK/KR/JP 股票、外汇和贵金属。
- 支持搜索、详情、K 线、provider 选择和连接状态。
- 用户可按账户或独立选择数据源，策略可单独绑定。
- 显示 provider、更新时间、延迟、stale 与切换状态。
- 陈旧行情明确警告；自动策略暂停新开仓。

实施状态（2026-08-24）：当前 instruments API 已在保持旧字段兼容的同时增加 contract v1、
四个当前市场、canonical instrument ID、market/calendar/capability 与公共 provider symbol 映射；
当前能力明确为 REST、display/research、display-only。Client UI 尚未消费新元数据，A/HK/KR/JP、
provider 选择、WebSocket、延迟展示和主备切换仍属于后续 T2.2–T2.4。

## 4. AI 助手

- 移除观察名单、分析标的选择和旧 8 卡片。
- 对话支持持久历史、取消、重试、Credits 预估/结算和错误恢复。
- 策略生成提供文字、参数和结构化 DSL。
- 生成结果进入校验、回测和准入，不直接执行订单。

实施状态（2026-08-24）：普通对话的持久历史、SSE、服务端所有权取消、provider abort、原请求幂等
重放和 Credits 预留/结算/释放单终态已实现；Client 点击“取消生成”直接执行且不弹确认框。固定
Credits 数值及模型/功能分档仍等待 P-08，当前按 provider 可信用量结算不能作为固定价格验收。

## 5. 交易大厅

- 七阶段使用对话气泡和状态时间线。
- Agent 列表、决策轮和策略可进入工作记录。
- 详情显示完整对话、策略版本、行情、风控、订单、成交和审计。
- Paper、Demo、Live 用不同徽标、book、回执和收益文案。

## 6. 策略广场

- 浏览、搜索、筛选、卡片、详情、作者、版本、回测、模拟盘、风险披露和费用。
- 客户可以创建草稿、投稿、查看审核状态和修订。
- 未通过准入的策略不能上架或跟单。
- 重大版本更新产生新版本并重新审核。

## 7. 跟单

跟单表单必须包含账户、投入金额、最大仓位、止盈止损、杠杆、最大亏损、策略版本、费用和风险确认。

生命周期准确显示配置、待确认、运行、暂停、风控阻断和停止。用户可随时停止；停止后的挂单、持仓和只减仓策略由执行合同决定。

## 8. 交易中心

- 右上角固定“连接交易所”。
- 账户连接显示 provider、环境、权限、IP 白名单、验证和 live readiness。
- Secret 仅提交，不回显。
- 订单、成交、持仓、余额、盈亏、对账和异常状态来自服务端事实。
- 未通过 live gate 时页面显示 blocker，不出现可产生真实订单的控件。

## 9. 会员、Credits、支付与优惠

- 月、季、年、终身套餐从服务端版本读取。
- 显示 USDT 价格、权益、Credits、AI 限额、增值服务、生效日和退款规则。
- Credits 显示固定对话扣费规则、余额、预留、结算和不可变流水。
- 支付只展示真实 provider 状态和订单，不生成假地址/二维码/回执。
- 优惠显示有效期、次数、适用套餐、叠加和退款恢复结果。

## 10. 提现与划转

在资金出站 Gate 未完成前，不显示可操作入口。未来入口必须显示网络、地址白名单、限额、服务费、冷静期、审批和链上状态，且与交易所交易凭证完全分离。

## 11. 主题、语言和可访问性

- 三浅三深六套主题。
- 默认英语；用户偏好 > 浏览器/地区 > 英语。
- 320/768/1024/1440 无非预期溢出。
- 键盘、焦点、`aria-live`、表单错误、对话框回焦和 reduced motion 完整。

## 12. 验收旅程

注册/验证 → 设备安全 → 行情选择 → AI 策略 → 回测/投稿 → 审核上架 → 跟单配置 → live gate → 订单/对账 → 消息/费用 → 停止与审计。

每一步覆盖成功、拒绝、超时、重复、权限不足、provider 不可用和恢复。
