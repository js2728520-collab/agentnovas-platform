# ADR-0004：统一 DSL V3、影子盘与模拟盘运行内核

## 状态

Accepted

## 日期

2026-08-18

## 决策

1. 历史回测、影子运行和模拟盘使用同一个 DSL V3 条件编译器与信号求值器；V1/V2 仅在运行时映射，不批量改写历史版本。
2. Runtime Worker 通过 PostgreSQL 租约、心跳窗口、fencing token、K 线唯一键和订单意图幂等键运行，不使用公开 HTTP 调度入口。
3. 七个运行角色分别保存市场数据、技术证据、策略结论、反方异议、确定性风控、执行意图和审计结果。确定性周期先完成并提交；市场摘要、反方异议和风控结论的 LLM 解释进入独立 PostgreSQL 队列，固定 Profile 修订与 Prompt 哈希。LLM 解释超时或失败不回滚周期，也不能改变信号、风控或订单意图。
4. 本期只接受 `shadow` 与 `paper`；所有真实永续和验证环境交易所订单路由均关闭。
5. 旧三套平台策略转换为受限 V3 版本。转换必须通过信号黄金测试和合同哈希确认；存在未平仓旧仓位、版本差异或风险参数越界时，切换事务整体回滚。
6. 生产部署固定为 Linux、Node.js、PostgreSQL 16+、三个 systemd 服务和 Nginx/Certbot 直连域名；不使用 Redis 或边缘 Runtime。

## 后果

- 回测和模拟行为差异可以通过相同输入重放定位。
- 模拟订单保存手续费、资金费率、策略/版本/订阅/周期引用和七角色事件。
- 运行事件同时保留不可变的确定性结论和独立解释状态；客户只看到解释模型名称，不会看到供应商、接口地址或 Key。
- 未通过标准验证的策略仍可保存、影子运行或模拟，但永久保留未验证标签，不能进入策略广场。
- 历史回测只提供证据，不构成未来收益承诺。
