# ADR-0008: 受邀付费 Beta 采用最小真实商业闭环

状态：Accepted  
日期：2026-08-20

## 决策

首批只开放 5–20 名受邀用户、三张官方策略、shadow/paper、in-app 与满足 Gate 的 Email。会费和 paper 盈利分成采用外部人工收款、站内凭证和双人复核。客户充值、自动支付、退款、社区策略、客户交易所密钥和真实订单不进入 Beta。

## 原因

现有工程具备研究/回测/模拟与三端基础，但身份、资金、外部 provider 和发布证据仍需收口。最小纵向切片可以验证客户价值、付费意愿和运营流程，同时避免托管资金、自动支付和真实交易带来的合规与安全扩张。

## 结果

- UI/文案必须持续标注模拟边界，不得把 Demo 证据称为客户成交。
- 七项平台商业披露任一未完整发布、哈希不一致或未完成双人复核，付费 Gate 失败。该 Gate 由产品版本化合同和技术证据控制，不依赖仓库外部团队交付，也不宣称工程文档构成法律意见。
- 新范围进入 GA backlog，不以临时开关绕过本 ADR。
