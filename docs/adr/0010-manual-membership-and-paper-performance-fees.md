# ADR-0010: 会费与 paper 盈利分成采用人工凭证和双人复核

状态：Accepted（受法务 Gate 约束）  
日期：2026-08-20

## 决策

四档会员使用版本化价格快照。外部付款后，Operations maker 记录脱敏凭证，不同 checker 复核；同一事务激活 entitlement、发放 credits、写账本/事件/outbox/audit。paper 盈利分成按上一个完整 UTC 周、三卡已平仓净收益、高水位与亏损结转计算；业务审批只形成应收，付款复核后才提交高水位。

## 不做

不生成链上地址、二维码、自动扣款、客户充值、自动退款或自动暂停会员；审批通过不表示外部资金已执行。

## 结果

重复凭证、重复决定和并发请求必须幂等。法务不批准模拟收益分成时，工程不得改成其他收费口径并上线。
