# ADR-0021：完整三端平台 V3 采用分阶段、按能力解锁的升级方式

状态：Accepted（产品范围）；实施与上线仍按能力受 Gate 约束

日期：2026-08-23

关联：PRD V3.0、ADR-0005、ADR-0008、ADR-0009、ADR-0010、ADR-0014、ADR-0019、ADR-0020

## 背景

需求方已确认《AgentNovas 完整功能需求确认书 V1.1》。目标产品不再局限于 5–20 人受邀 Paper Beta，而是完整的 Client、Operations、Maintenance 三端交易平台，包含多市场行情、AI 策略、客户策略市场、自动跟单、真实交易目标、权限注册链接、完整运营和技术控制面。

当前仓库已经具备三端隔离、RBAC、Paper/Demo、账本、执行服务、客户凭证隔离和实盘记账基础，但真实交易仍有明确 blocker；现有生产证据只证明受控 Beta/Paper 基线。直接把 PRD 目标写成“已完成”会制造假状态，直接删除旧 ADR 又会丢失安全决策和实施证据。

## 决策

### 1. PRD V3.0 成为目标产品真源

`docs/product/PRD.md` 定义最终产品目标、首期范围、需求冲突解释和待补产品参数。新的目标功能不再写入 Beta backlog 后被默认遗忘。

### 2. 当前实现与目标能力分层

所有能力使用以下状态：

- `CURRENT`：当前实现已存在且有证据。
- `PARTIAL`：存在基础，但未满足 V3 合同。
- `TARGET`：已确认目标，尚未实现。
- `BLOCKED`：已确认目标，但被产品参数、安全、合规、外部依赖或技术 Gate 阻断。
- `RETIRED`：不再进入目标产品。
- `HISTORICAL`：不可改写的历史决策、评估或发布证据。

### 3. 高风险能力按能力解锁

真实现货、USDT 永续、自动跟单、客户密钥、提现/划转和 CI/CD 触发部署分别拥有独立 Gate。一个能力通过不得自动解锁另一个能力。所有 Gate 完成前，当前失败关闭路径继续有效。

实盘订单必须继续由确定性执行服务负责。LLM 只能提出或解释交易意图，不能跳过验证、风控、对账、熔断或用户确认。

### 4. Operations 取消组织架构展示，保留数据范围事实

Operations 不再展示组织树、汇报关系图或组织管理页面。系统仍保留分公司、角色归属、客户归属和 assignment-bound scope，用于权限、报表和审计。

内部账号改为角色/权限注册链接自助注册：长期可重复使用、手动作废、重生成撤销旧链接、注册成功立即赋予对应权限，无人工审批。链接不能越级，token 只存摘要，所有生命周期事件审计。

### 5. 发布控制面采用 CI/CD 委托

V3 目标允许 Maintenance 触发部署和回滚，但不允许浏览器执行任意 Shell、SSH、数据库脚本或持有长期基础设施密钥。控制面只调用预先定义、版本化、最小权限、可双审的 CI/CD 工作流。

现有“只登记发布证据”的实现继续作为 `CURRENT` 基线；V3 执行能力在专项 Spec、威胁模型和 Gate 通过前为 `BLOCKED`。

### 6. 历史记录不改写

既有 ADR、`docs/releases/` 和带日期的评估保留原文。通过 `docs/DOCUMENT_STATUS_MATRIX.md` 标注其生命周期和替代文档；需要改变决策时新增 ADR，不删除旧 ADR。

## 对既有 ADR 的影响

- ADR-0008：在“最终目标产品范围”上被本 ADR 取代；在“当前运行时仍保持受控 Beta/Paper”上继续作为历史阶段边界。
- ADR-0005：三端、RBAC 和数据范围保留；组织页面、内部邀请方式和发布控制面进入 V3 迁移。
- ADR-0009：Paper/Demo 隔离继续有效；真实客户执行加入后必须增加 live book，不能混写。
- ADR-0010：现有人工会员/Paper 分成保留为当前基线；V3 需要策略作者分账和真实跟单收费合同。
- ADR-0014：不可变版本证据继续有效；实际触发部署由 V3 CI/CD 控制面扩展，不覆盖历史事实。
- ADR-0019/0020：作为真实执行、凭证隔离、对账和实盘记账基础继续有效；不得因为 PRD 确认而跳过剩余 blocker。

## 后果

- 产品、当前实现和历史证据不再互相覆盖。
- 全面升级必须按依赖顺序推进，不能以“大改造”名义同时打开资金、交易和部署权限。
- 每个阶段都必须产生可验证的合同、代码、数据迁移、自动化测试、浏览器证据、Runbook 和回滚方案。
- 未补齐的产品参数继续阻断对应切片，不阻断无关基础能力。

## 不做

- 本 ADR 不授权生产真实交易、提现、划转、真实退款或自动部署。
- 本 ADR 不选择具体合规结论、行情供应商、WAF、交易所优先顺序或收费数值。
- 本 ADR 不把 Target 文档当作当前生产能力证明。
