# ADR-0001：原生 AI 对话与受限策略 DSL

- 状态：Accepted
- 日期：2026-08-16
- 关联需求：AI-001 至 AI-006

## 背景

AgentNovas 已有 OpenAI Compatible 配置、策略工作室、社区策略草稿和历史回测，但独立 Agent 对话仍是静态演示；策略聊天由客户端提交历史；“生成候选规则”只切换前端状态；回测实际执行固定指标组合，未执行用户填写的自然语言规则。

QuantDinger 可以作为产品与架构研究参考，但直接复制其前端存在授权边界，也无法解决 AgentNovas 现有 PostgreSQL 身份、租户、策略审核和风控模型的衔接问题。

## 决策

1. 在 AgentNovas 内原生实现持久化对话与策略生成，不直接复制 QuantDinger 前端代码。
2. 将 LLM 视为不可信的提案器，仅允许输出版本化 JSON DSL。
3. 由确定性白名单解释器执行 DSL；绝不执行 LLM 生成的 Python、JavaScript、SQL、Shell 或订单指令。
4. 复用现有用户/系统 LLM 配置、客户会话、PostgreSQL、社区策略草稿和历史回测链路。
5. V1 只生成研究草稿，生成、对话和回测均不连接订单执行。

## 结果

- 优点：租户与审计边界一致；策略可以验证、复现和回测；不增加任意代码执行面；降低第三方前端授权风险。
- 代价：V1 策略表达力有限；每增加一种指标或组合逻辑都需要新增类型、校验、解释器和测试。
- 后续：真实模拟盘执行、做空、组合策略、长期记忆和工具调用必须单独提案并进行威胁模型评审。
