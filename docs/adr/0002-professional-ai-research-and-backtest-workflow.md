# ADR-0002：专业 AI 研究上下文与原生回测闭环

- 状态：Accepted
- 日期：2026-08-18
- 关联规格：`docs/ai-research-backtest-v2.md`

## 背景

QuantDinger 的 AI 专业度来自意图路由、会话工作记忆、真实研究上下文、回答结构和工具工作流，而不是单一提示词。AgentNovas 已完成租户隔离的持久化对话、受限 DSL、策略版本和历史回测，但 AI 上下文较薄，策略详情与回测参数也未形成完整用户界面。

## 决策

1. 原生扩展 AgentNovas 的 AI 上下文和回答契约，不复制 QuantDinger UI。
2. 使用服务端真实 K 线计算有限技术快照，并把来源和时间传给模型。
3. 从所属会话提取短期工作记忆；不新增跨会话向量记忆。
4. 保留 JSON DSL 白名单解释器，不执行 LLM 生成的任意 Python。
5. 在现有策略和回测报告表上增加详情、参数预设和报告查看接口，不新增表。
6. 默认回测使用包含手续费和滑点的实盘对齐预设；探索预设必须明确展示。

## 结果

- 获得 QuantDinger 工作流层面的专业能力，同时维持 AgentNovas 的租户、审核和无任意代码执行边界。
- 回测仍受 1,000 根 K 线限制，暂不提供 QuantDinger 的多市场长区间、参数寻优或 Python 策略表达力。
