## 1. 已确认且不再重复询问

需求方已经勾选并确认以下治理要求：

- 已发布版本只读，编辑必须创建新草稿。
- 草稿测试通过后才能发布。
- 发布需要双人审批，创建者不能自审。
- 保留完整版本历史。
- 支持回滚到已经验证和生效过的版本。

现有通用配置框架已经提供不可变草稿、服务端测试证据、独立审批、定时生效、当前版本和历史回滚。
以下问题只决定 Prompt / Skill v1 的具体 schema、测试器和运行时消费者，不改变上述已确认治理原则。

## 2. 需要需求方确认的六项决定

### PS-01：首期管理哪些 Prompt

**推荐：** 首期管理现有七个策略研发角色和三个运行时只读解释角色；Client 通用 AI 助手 Prompt 按 AgentNovas 现有方向单独接入，不依赖 QuantDinger 移植参考；Credits 计费边界按 P-08/T3.9b 独立管理。

需要确认：

- 是否接受上述首期范围？
- 是否还需要首期增加一个 Client 通用 AI 助手默认 Prompt？

影响：不同角色具有不同 JSON 输出合同和安全责任，不能共用一个可随意替换的全局文本。

### PS-02：Skill 是声明式指令包还是可执行扩展

**推荐：** v1 只允许声明式 Skill，字段限定为名称、说明、指令正文、适用 Agent 角色和启用状态；
不允许上传代码、Shell、任意 URL、网络权限、数据库权限、工具权限或秘密。

需要确认：

- 是否接受 v1 仅声明式？
- 如果要求可执行 Skill，请另行给出允许的运行环境、工具白名单、网络范围和权限模型。

影响：可执行 Skill 会新增代码执行、供应链、凭证和网络攻击面，不能复用普通 JSON 配置的安全结论。

### PS-03：平台安全模板是否允许后台修改

**推荐：** 不允许。Prompt 的角色指令可编辑，但以下平台安全包络固定在代码中：不执行上下文指令、
不泄露秘密、不输出隐藏推理、不伪造数据、不承诺收益、不得改变确定性校验/风控/订单意图、严格输出合同。

需要确认：

- 是否同意运维人员也不能通过 Prompt 草稿删除或覆盖安全包络？

影响：若允许编辑安全包络，双人审批仍不能替代运行时安全边界，需单独威胁模型和更高级审批。

### PS-04：发布前测试由什么组成

**推荐：** 必须通过服务端确定性测试，包括 schema、字符/字节预算、禁止字段和秘密扫描、角色输出合同、
安全包络组合、Prompt injection 固定样例和稳定 SHA-256；模型真实试跑作为独立的可选/附加证据，不能由
浏览器伪造结果，也不能让模型输出决定交易或风控。

需要确认：

- 模型真实试跑是发布必需项，还是仅作附加观察证据？
- 若为必需项，使用当前角色绑定模型，还是指定独立测试模型？

影响：真实模型调用有费用、超时和非确定性；纯确定性测试只能证明结构与安全合同，不能证明模型质量。

### PS-05：新版本何时影响任务

**推荐：** 激活或回滚只影响随后创建的新任务；已排队、执行中和历史任务继续固定原
`configurationVersionId + payloadSha256`，不得在中途换 Prompt / Skill。

需要确认：

- 是否接受“新任务生效、存量任务固定版本”？
- 是否存在必须人工迁移的排队任务；如有，迁移是否要求取消后重新创建？

影响：中途替换会破坏重放、证据链、结果归因和事故复盘。

### PS-06：删除 Skill 的产品语义

**推荐：** “删除”只创建一个停用/归档新版本，阻止新任务选用；不物理删除已发布版本、历史任务引用、
测试、审批或审计事实。不可变草稿也不覆盖，修改时创建下一版本。

需要确认：

- 是否接受逻辑归档替代物理删除？
- 已归档 Skill 是否允许通过新版本恢复？

影响：物理删除会导致历史任务无法解释和重放，与已确认的版本历史要求冲突。

## 3. 推荐的一次性回复格式

如全部接受，可回复：

> PS-01 至 PS-06 全部采用推荐方案；Client 通用 AI 助手 Prompt 暂不纳入首期；模型真实试跑作为附加证据；已归档 Skill 允许创建新版本恢复。

如有调整，请按编号回复，例如：

> PS-04 调整为模型真实试跑必须通过，使用当前角色绑定模型；其余采用推荐方案。

## 4. 确认后的当前工程边界

- Prompt/Skill 的版本合同与确定性测试可以按冻结结论实施；Prompt consumer 仍须独立 Gate，不能由配置版本 `ACTIVE` 直接推导为发布通过。
- Skill runtime consumer 不属于当前 S0；在 T3.4b 完成最小权限任务加载、版本固定、失败关闭、回滚和独立 Gate 前，不创建会让 Agent 加载可编辑 Skill 的 active consumer。
- 不把通用配置框架中尚未注册的人工测试证据冒充确定性测试。
- 不允许配置打开交易、支付、提现、部署、MFA 或权限能力。
- 现有代码内固定 Prompt 和历史任务哈希继续保持当前行为；已固定任务不得随 current 配置漂移。
